# Evaluation notes

One note per group of consumer features that were weighed for the core and not built there. Each note says, entry by entry, whether
the feature is generic or specific to the consumer that built it, what is already in the core, what the core would need to carry it,
and a recommendation with the decision it needs. Nothing in a note is built or promised; a note exists so the owner can decide with
the facts in one place.
